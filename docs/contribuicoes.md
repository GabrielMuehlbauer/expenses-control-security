# Contribuições e revisão

O código inicial é proveniente dos repositórios registrados em [origem.md](origem.md). Este repositório registra somente o novo trabalho; não atribui autoria dos commits antigos a novos participantes.

Fluxo recomendado: uma tarefa delimitada por branch, PR com descrição do comportamento, testes executados e revisão por outro integrante antes da integração. Usar nomes como `feat/receitas`, `fix/validacao-despesas` e `test/isolamento-usuarios` conforme a mudança real.

| Trabalho | Registro |
|---|---|
| API e frontend originais | Gabriel Muehlbauer; commits de origem em origem.md |
| Unificação, segurança, integração, testes e documentação desta entrega | Desenvolvidos com assistência do Codex, sob orientação do responsável pelo projeto |
| Revisão humana de outro integrante | Ainda não registrada |

Ao dividir tarefas, substituir a ausência de registro por links para os PRs e revisões realizados. Não preencher nomes ou aprovações presumidas.
