Este projeto reúne duas implementações de Gabriel Muehlbauer, mantendo a licença MIT:

| Parte | Repositório de origem | Commit de referência |

| API | https://github.com/GabrielMuehlbauer/expenses-control-api | 07b0774fd1ed574c801bbd41103341b1134c4954 |

Conforme decisão do responsável pelo projeto, o repositório unificado começa com um histórico novo. Os commits anteriores não são importados. Os repositórios de origem permanecem intactos. O frontend conserva a identidade visual, componentes React e CSS Modules; a API mantém Express, Sequelize, MySQL e a divisão entre rotas, views HTTP, controladores e modelos.

Arquivos de ambiente, tokens da coleção Postman, dependências instaladas, builds e bancos locais não fazem parte da importação. Os autores e a licença do código original são preservados pelos arquivos LICENSE e por este registro.

As correções e implementações foram desenvolvidas com assistência do Codex. A participação dos integrantes deve ser registrada com tarefas, commits, PRs e revisões efetivamente realizados; assistência automatizada não equivale a revisão humana de outro integrante.
